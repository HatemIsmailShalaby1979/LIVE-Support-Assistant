LIVE Support AssistantView source on GitHub
Browser prototype / Current build 2026-09-25

A small support tool with explainable behaviour.

A browser prototype that uses on-device semantic retrieval and a deterministic confidence gate over public TikTok LIVE help content, then returns a relevant policy or escalates the case.

Where it stands: a portfolio prototype. Five public policy entries, no generative model, and no application backend. First use downloads the pinned embedding model and ONNX runtime from third-party CDNs. Command Centre transport and production authentication are not built. Not a production support system. No external audit and no revenue.

What this project demonstrates

Simple by design

Semantic retrieval finds relevant passages; a deterministic margin gate decides whether to answer or escalate.

Privacy boundary

The current prototype evaluates customer text in-browser and does not configure an application transport.

Operational lesson

Start with the smallest useful workflow before adding complexity.

Honest boundary

The assistant searches five policy entries and nothing more. It uses a local embedding model but no generative language model, does not handle account-specific cases, and is not connected to authentication, ticketing, or a Command Centre transport. Its answers can go stale because the policy text is maintained by hand from public help-centre pages.
